# Security and device reports

This developer preview performs local file validation and metadata analysis. It does not connect to a PS5, change firmware, install an exploit or send payloads.

For a suspected security issue, use GitHub's private vulnerability reporting if available. Otherwise open a minimal issue asking for a private reporting channel without including the exploit, credentials or sensitive device data. Do not post personal IP addresses, console identifiers, tokens, keys or game files.

A future device-writing release requires an explicit, documented installation target, integrity checking, conflict refusal, interruption handling and verified recovery. A manifest digest confirms the selected manifest's identity, not the trustworthiness of its author or the safety of the binary it describes.
