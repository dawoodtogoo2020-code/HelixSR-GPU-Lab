“CONTROL Resonant” is one title. This project makes no claim of support for a Resident Evil game.

The regular PS5 lab result does not establish PS5 Pro compatibility, another region/build, another firmware or an independently configured console. UI availability and successful application launch do not establish upscaler activation.

## Why each game needs an adapter

An FSR label does not identify a universal replaceable interface on PS5. An adapter must find the actual frame resources, understand formats and motion/depth conventions, honor barriers and lifetimes, write the correct output, and recover the original path. Updates can change those assumptions.

Discovery, metadata checks, numerical tests, live rendering, benchmark qualification and a public installation are separate milestones. Only a runtime-qualified, distributable combination should become selectable in a future released application.
