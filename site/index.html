05 / COMMON QUESTIONS

Before you download.

Will it work with every PS5 game that uses FSR?

That is a long-term direction, not current support. Each game build needs a validated native adapter, the right frame resources, synchronization and an original-path recovery procedure. A scanner finding FSR is not enough.

Can I install it on a stock retail PS5?

This preview has no console installer and certifies no stock-retail or firmware compatibility. The private lab uses a compatible homebrew environment. The project does not install that environment or provide exploits.

Does “CONTROL Resonant” mean two supported games?

No. CONTROL Resonant is the title in the lab's test records. There is no verified Resident Evil support in this project.

Could a single payload make installation easier?

Yes, payload delivery is a planned option. It can automate installation once the components are distributable and tested. It cannot make an unqualified game compatible or replace missing model and adapter work.

Is this the official HelixSR project?

This is independent PS5 research. Lone Wolf's HelixSR is the upstream PC project. This preview contains original host tools, not its runtime or generated model assets.
