03 / GET STARTED

Install in
three steps.

You need a jailbroken PS5 running ftpsrv, pldmgr and ShadowMount+, and a supported game at its exact version. The installer runs on a Windows, Mac or Linux PC.

Download v0.2.0-beta ↗

Windows: nothing else needed · Mac/Linux: Python 3.10+

QUICK STARTPUBLIC BETA
  1. Download and unzip the betaHelixSR-GPU-Lab-v0.2.0-beta.zip from Releases.
  2. Run the installer
    install.bat   (or: sh install.sh)
  3. Answer its questionsYour PS5's IP address, whether it is a PS5 Pro, and yes to NVIDIA's DLSS license. Then start the game and close it when asked.
Then on the PS5

Open HelixSR GPU Lab. Cross switches HelixSR on or off, and Triangle starts the game. To remove everything, run uninstall.

05 / COMMON QUESTIONS

Before you download.

Will it work with every PS5 game that uses FSR?

That is a long-term direction, not current support. Each game build needs a validated native adapter, the right frame resources, synchronization and an original-path recovery procedure. A scanner finding FSR is not enough.

Can I install it on a stock retail PS5?

No. It needs a jailbroken PS5 running ftpsrv, pldmgr and ShadowMount+. The project does not provide exploits or install that environment. It has been tested on a regular PS5 on firmware 11.60 and a PS5 Pro on firmware 13.60.

Does the download contain game or NVIDIA files?

No. The installer builds HelixSR's files on your PC from your own copy of the game, which it reads from your PS5. It also needs NVIDIA's DLSS DLL: it downloads that from NVIDIA after you accept NVIDIA's license, and deletes it afterwards.

Does “CONTROL Resonant” mean two supported games?

No. CONTROL Resonant is the title in the lab's test records. There is no verified Resident Evil support in this project.

Can I undo it?

Yes. Run uninstall. It removes every file the installer added and puts back anything it replaced, which it backed up to your PC first. The ON/OFF switches take effect straight away.

Is this the official HelixSR project?

This is independent PS5 research. Lone Wolf's HelixSR is the upstream PC project. GPU Lab's PS5 ports of HelixSR are distributed with Lone Wolf's permission.
